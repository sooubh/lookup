LOOKUP Privacy & Demo Scenarios

Deterministic test scenarios demonstrating local perception, automated sensitive data redaction, and user consent gates before cloud egress.

🔍 1. Local Perception

Raw DOM and visual pixels are inspected on-device via local heuristic detectors and WebGPU perception.

🛡️ 2. Policy Enforcement

Configurable Strict and Balanced policies classify data into Safe, Redact, Ask User, or Block.

🚪 3. Egress Trust Gate

Zero unredacted sensitive tokens leave the machine. Outbound AI requests receive only sanitized DOM.
